# MNYPhoto theme
A full WordPress site, for photogrpahy buisness.

## Commands
- `npm run dev` watches source styles and scripts.
- `npm run build` compiles production browser assets.
- `npm run lint:php` ...
- `npm run package` creates the release ZIP outside /themes/ at /wp-content/.. here.
- `npm run test` runs lint, build, and theme contract checks before release. PENDING

Edit source in `src/`; do not hand-edit generated files in `dist/css` or `dist/js`.
