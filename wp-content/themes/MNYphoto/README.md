# MNYPhoto theme
A full WordPress site, for photogrpahy buisness.

## Commands
- `npm run dev` watches source JavaScript and SCSS files with Webpack.
- `npm run build` creates minified production JavaScript and CSS bundles with Webpack.
- `npm run lint:php` validates PHP syntax across the theme.
- `npm run package` creates the release ZIP outside /themes/ at /wp-content/.. here.

Edit source in `src/`; do not hand-edit generated files in `dist/css` or `dist/js`.
